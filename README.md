# NEWOS toolchain

Host-executed `x86_64-elf` cross-toolchain scripts, examples, and optional shallow GCC 16.1.0 source submodule. The compiler runs on the host and targets NEWOS; it is not a native compiler running inside NEWOS. GCC source is optional: the ordinary OS build does not initialize or fetch it.
